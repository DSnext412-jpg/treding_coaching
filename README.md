# 📖 About

**Trading Coaching** is a modern educational platform built to help aspiring traders understand financial markets through structured learning, live mentorship, and practical trading concepts.

The platform combines interactive learning, progress tracking, and premium course management into one seamless experience.

# 🚀 Quick Start

Clone the repository

```bash
git clone https://github.com/DSnext412-jpg/treding_coaching.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
